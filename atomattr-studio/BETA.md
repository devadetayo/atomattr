# AtomAttr Studio: beta guide

Thank you for testing. Studio runs entirely in your browser: there is no account and nothing is uploaded.

## Before you start
- Use a recent Chrome, Edge, Safari or Firefox on a laptop or desktop. Tablets and phones are not supported for editing yet.
- Projects are saved **in this browser only**. Use File → Save to file (.ast) regularly, and before clearing site data or switching browser.
- Photos in the Library are Unsplash placeholder links: they need an internet connection.

## What to try (about 30 minutes)
1. **Build a page**: start a project, add blocks from the Library (Expand opens a wide view), edit text, drag, resize.
2. **Responsive**: switch Desktop / Tablet / Mobile and check each looks right.
3. **Animation panel**: add an entrance animation, a border beam and an animated background (Effects tab).
4. **Dark mode**: insert any block, add a Dark mode toggle from the Library, preview dark.
5. **Import**: File → Import…, try an HTML file, a React component with its CSS, a Word document and a Markdown file.
6. **Data pages**: make a collection, a list page and an item page; check the exported links.
7. **Export**: export the site as a ZIP, unzip it and open `index.html`. Try the React export too.
8. **Recover**: reload the tab mid-edit and confirm your work is back. Undo and redo a few steps.

## Known limits
- No server features: hosting, GitHub sync, AI, live co-editing, analytics.
- Library view and save counts are per browser.
- Import is best-effort: React imports keep static markup only (no state or logic); PDFs cannot be imported; linked stylesheets only apply when dropped with the page.
- Dark mode for Library blocks is automatic; hover colours are not re-mapped in dark; gradients are not converted.

## Reporting a problem
Help → **Send feedback or report a problem…** (or click the BETA badge). Describe what happened, then copy or download the report and send it to whoever gave you this build. The report holds your browser, screen size, project size and recent errors, and none of your project content. If Studio ever shows "Something went wrong", press **Download project backup** before reloading.

Useful details: what you clicked, what you expected, what happened, and whether it repeats.
