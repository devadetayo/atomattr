The Future of CSS

Native CSS keeps absorbing what tools used to do. Where does an attribute-first approach fit?

DdevadetayoAtomattr

This is an opinion piece. It reflects the author's view, and reasonable people will disagree.

CSS has been busy

Features that once needed a preprocessor or a framework now ship in browsers: custom properties, nesting, :has(), container queries, cascade layers and color-mix(). Atomattr itself leans on some of them: its alpha colors compile to color-mix, and its tokens are CSS variables.

The direction is clear. The platform is taking over the jobs that tools used to do, and the tools that last will be the ones that get thinner as it does.

What that means for tooling

  • Less translation. When the browser can do something natively, a tool should emit that and step aside.
  • Tokens stay central. Design decisions, such as a palette or a spacing scale, belong in variables that anyone can override.
  • The authoring surface still matters. Native CSS answers "what can styles do". It does not answer "where do I write them", and that is where utility systems earn their place.

Where attributes fit

HTML is the one language every web page already has. Attributes keep styling decisions next to structure, readable and searchable, and they work for dynamic markup without a compiler. The cost is real: they need a runtime, and they trade away some of the guarantees of precompiled CSS (we wrote about that).

Newer additions to CSS, such as broader support for reading attribute values with attr(), suggest the platform is warming to the idea that attributes can drive presentation. If that matures, parts of an engine like ours could move from JavaScript into the browser. We would count that as a win.

What would change our mind

  • A native way to express responsive and state variants inline.
  • Build-free tooling that matches runtime ergonomics with no script cost.
  • Evidence from real projects that attribute-driven styling hurts maintainability at scale.

The last one matters most, and it needs people building real things. If that is you, tell us what you find.
