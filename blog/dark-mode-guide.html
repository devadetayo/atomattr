Mastering Dark Mode in 5 Minutes

One class on the root element, one prefix on your attributes.

DdevadetayoAtomattr

Dark mode in Atomattr is a root class plus a prefix. You decide when the class is on; the attributes decide what changes.

Step 1: the class

The dark- prefix generates rules scoped under html.dark. So dark mode is active whenever the root element carries the dark class.

html
<html class="dark">

Step 2: the prefix

Put dark- in front of any attribute to set its dark-mode value. The light value stays on the plain attribute.

html
<body bg="#fff" dark-bg="gray-950" text="text" dark-text="gray-50">
  <article p="6" rounded="2xl" border="1px solid gray-200" dark-border-color="#ffffff/10">
    Adapts to the theme.
  </article>
</body>

Step 3: a toggle with memory

A toggle only needs to flip the class and remember the choice. This is the pattern the Atomattr site itself uses (the storage key is just a name you choose):

html
<button id="theme" aria-label="Toggle theme"><i class="ri-contrast-line"></i></button>

<script>
  var root = document.documentElement;
  var saved = localStorage.getItem("atomattr-theme");
  var prefersDark = matchMedia("(prefers-color-scheme: dark)").matches;
  root.classList.toggle("dark", saved ? saved === "dark" : prefersDark);

  document.getElementById("theme").onclick = function () {
    var dark = root.classList.toggle("dark");
    localStorage.setItem("atomattr-theme", dark ? "dark" : "light");
  };
</script>
Avoid a flashRun the first four lines in the head, before the body renders, so the right theme is applied before first paint.

Semantic colors help

Names like primary, muted, border and surface resolve through --aa-color-* CSS variables, and the defaults stylesheet adjusts variables under html.dark. Using them means fewer dark- attributes. Override a variable to retheme everything that uses it:

css
:root { --aa-color-primary: #7c3aed; }

Checklist

  • Set text and background for the page body, in both modes.
  • Give borders a dark value, since light grays disappear on dark surfaces.
  • Check images and shadows: a logo may need a dark variant.
  • Test the toggle with and without a saved preference.
