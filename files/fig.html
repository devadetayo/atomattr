Before you copy.

Is AtomAttr UI a component package?

No. It is a library of patterns you preview and copy. You own the source from the moment you paste it.

Do I need AtomAttr installed to use a pattern?

Yes. Patterns are written in Atomattr attributes, so your page needs the defaults stylesheet and script. The install guide covers both.

Can I change the colors?

Yes. Patterns use semantic tokens like primary and muted, so your theme controls the actual values.

Which formats are available?

Each pattern is published as HTML and as React source.
