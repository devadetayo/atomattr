Search the reference

Use the search field on this page to look up an AtomAttr attribute such as grid-cols, a CSS property such as aspect-ratio, a value token such as primary, or a modifier such as hover. Results link to the matching guide or the relevant reference table.

The search index is assembled from the registered attribute dictionary, supported tokens and prefixes, and the documentation navigation. If a name is not indexed, check the source dictionary or search the page for the CSS property it should control.

Search tips

Try a short part of a name if you do not know its exact spelling. Search font for font-related attributes, container for query documentation, or video for the aspect ratio preset. Use the cheatsheet for a complete attribute-to-property table.
